# Stories affected by recommended language modifications

Derived from the language review. Use this to plan illustration/audio regeneration.

## Regeneration rule of thumb

| Change type | Illustrations (`.webp`) | Audio (`.mp3`) |
|-------------|-------------------------|----------------|
| Punctuation / quote style only (`—`, `«»`, ASCII) | **No** | **No** (spoken words unchanged) |
| Paragraph splits without rephrasing | **No** | **Usually no** |
| Wording / fluency rewrite | **Only if scene/meaning changes** | **Yes** |
| New scenes or character actions | **Yes** | **Yes** |

**Summary:** Tier 1 = **10** stories (structure / possible rewrite). Tier 2 = **82** stories (dialogue punctuation only). **5** stories appear in both.

If you only apply the review’s punctuation + paragraph-split recommendations **without rewriting meaning**, expect:

- **Illustrations to regenerate: 0** (unless you later change story content)
- **Audio to regenerate: mainly the Tier 1 set (10)**, and only if phrasing changes when splitting
- **Tier 2 (82): text files only** — no illustration/audio regen required for punctuation unification
