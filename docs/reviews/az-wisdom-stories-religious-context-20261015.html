Religious references in Azerbaijani Wisdom Stories

Review of all 261 current DOCX documents in the Azerbaijani Wisdom Stories folder, including both author subfolders. Each document was read in full. Illustrations, audio, translations and website pages were not assessed.

89 files listed; 172 files with no identified religious reference. 53 religious characters, beliefs, practices or settings; 25 passing expressions, blessings and cultural vocabulary; 2 religious attribution only; 3 possible religious context — interpretation uncertain; 6 verse and poems — listed separately.

Classification describes what is present in the text; it is not a recommendation to remove or rewrite it. A religious character can appear in a story whose lesson is otherwise universal. Everyday expressions are separated from substantive religious content.

Two points to note

mullah-and-the-scholar.docx is titled “Vəzir və alim.” The current text features a vizier and a scholar, not a mullah. It does contain “Maşallah” and “vallah.”

credit-ledger.docx contains two complete versions of “Nisyə dəftəri.” Both refer to Allah and Ramadan; the first also mentions Judgment Day. Both versions were considered, but the file is counted once.
