# Comprehensive QA — 20 October 2026

The local fixes and regression checks are complete for the coverage below. This is not an unrestricted production certification: the unresolved items and untested integrations are listed explicitly. No deployment, commit, push, or live form submission was performed during this audit.

## Fixed

- Story comparison reordered some source credits and treated a poem's final stanza as its moral. It now preserves paragraph order, recognizes reviewed moral/source labels, and retains poem line breaks. All five comparison pages now have a main landmark.
- Source HTML contained inconsistent asset cache references. References were refreshed, including a new comparison-script version, and the publish package was rebuilt.
- QA omitted German in its language and browser matrices. German is included; browser tests now use an isolated HTTP preview instead of file URLs.
- The German preservation baseline preceded approved editorial edits. The updated tracked baseline was checked against the approved correction log and the independent editorial verifier, including unchanged image hashes.
- The translation manifest marked 747 missing audio files as complete. Their status is now pending; audio remains excluded from publication.
- The API static mount omitted German and could expose authoring trees in production. Enabled languages are loaded from configuration; production requires the publish tree.
- API and local-feedback outbox filenames could collide within one second. Random suffixes now preserve separate messages and attachments.
- CI now runs all tooling/API regression tests, source parity, German preservation, structural checks, and the publish crawler. New reusable auditors check story synchronization and publish links/metadata/file exclusions.

## Remaining findings and limits

1. **Medium — PHP feedback abuse controls:** source inspection found a honeypot but no endpoint rate limiter, incomplete server-side text length limits, and attachment extension validation without enforcing detected MIME types. Hosting protections may exist but were not established. PHP is unavailable locally; email delivery and upload handling were not exercised, and no real feedback was sent. Harden and test this endpoint in a PHP-capable staging environment before claiming it is fully verified.
2. **Medium — full-build reproducibility:** the legacy website generator depends on CPython 3.14 bytecode and is not reproducible from readable tracked source alone. The documented restriction against recovering/replacing the bytecode was respected. The deployment packager was executed successfully; a fresh full editorial site generation was not.
3. **Performance risk — large home-page DOM:** the English home page contains approximately 19,212 DOM nodes, 256 articles, and 522 image elements. Responsive behavior passed, but no Lighthouse/Core Web Vitals or production load-test result is claimed. Pagination or incremental rendering warrants a separately measured change.
4. **Integration/coverage limits:** real SMTP, production database/auth deployment, PHP runtime behavior, cross-browser Safari/Firefox, screen-reader testing, and comprehensive dependency-vulnerability scanning were not verified. The dormant account backend should not be treated as production-approved by these local tests.
5. The one production connection-reset URL needs a successful retry or hosting investigation. No release was made to fix it in this audit.

## Repeating the automated checks

Install `tools/requirements.txt` and `api/requirements.txt` into an isolated environment. From the repository root run:

```text
python -m pytest tools -q
python tools/audit_story_sync.py --output docs/reviews/ci-story-sync.json
python tools/test_german_wisdom.py
python tools/build_deployment.py
python tools/full_site_qa.py --structural
python tools/audit_publish_tree.py --output docs/reviews/ci-publish-tree.json
```

From `api/`, run `python -m pytest app -q`. The comparison regression test also requires Node on PATH. Browser acceptance checks require a local HTTP preview and interactive browser verification.
